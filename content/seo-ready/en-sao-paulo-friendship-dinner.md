But on Fanju app, the host specifies the dish, the number of seats, the tone of the evening. That predictability lowers the barrier to showing up. <p>The venue itself also communicates intent. A dinner set in a clean, welcoming living room with a properly set table reads differently than one squeezed into a kitchen nook with folding chairs.
