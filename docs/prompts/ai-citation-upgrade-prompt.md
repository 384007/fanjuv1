# AI Citation 内容升级专用 Prompt（2026 版）

**用途**：用于 Claude / GPT / 内部 Modal worker 对现有 Pillar / 对比页 / 高优先级城市文章进行「可引用单元」专项加强。

**核心约束**（必须严格遵守，否则拒绝输出）：
- 永远把传统 SEO 健康度放在第一位。任何改动都不能让页面看起来更薄、更营销化、更模板化。
- 每篇文章必须有至少 1-2 个**本页独创**的命名框架 / 精确 checklist / 第一性原理观察。
- 禁止任何两个页面的结构相似度超过 60%。
- 语气永远克制、专业、有边界感，禁止油腻、FOMO、结果承诺。
- 品牌表述统一为「饭局 Fanju」（中文页）或「Fanju」（英文页）。

---

## 任务指令

你现在要升级页面：`[页面路径]`

当前页面核心目标词：`[核心关键词，例如：饭搭子 / 饭局 Fanju / 如何找饭搭子]`

请按以下顺序输出：

### 1. 诊断（简短）
- 当前页面最强的 1-2 个部分（AI 可能已经会引用）
- 当前最缺失的高价值可引用单元类型（框架 / checklist / 独特观察）

### 2. 新增/强化可引用单元设计（必须原创）
为本页设计 **2-3 个** 高质量可引用单元，每个必须包含：
- 单元名称（建议带独特命名，便于 AI 记忆和引用）
- 完整内容（可直接插入页面的格式）
- 为什么这个单元对 AI 引用价值极高（1-2 句）

推荐类型（至少覆盖 2 种）：
- 原创阶梯 / 模型 / 四象限 / 定律
- 带「通过 / 失败」标准的精确判断 Checklist（7 条左右最佳）
- 第一性原理观察（「只有长期做这件事的人才能看出」的那种洞见）
- 强对比框架（如果本页是 vs 类页面）

### 3. 具体插入建议
- 建议插在页面哪个现有 section 之后/之前
- 是否需要替换现有某个弱 section
- 英文版本是否需要独立创作（如果是 Pillar 页，必须是）

### 4. 反模板化检查
- 本次改动后，本页与本站其他主要 Pillar 页的结构相似度大约是多少？
- 如何进一步拉开独特性？

**额外铁律**：

- 所有新内容必须能让一个对这个领域一无所知的人读完后，觉得「这个东西只有写这篇文章的人能想出来」。
