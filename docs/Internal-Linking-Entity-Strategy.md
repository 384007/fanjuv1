## 2. 内链原则（必须严格执行）

1. **每个 Tier 2 页面必须至少链接到 2 个 Tier 0/Tier 1 页面**（自然语境中）。
2. **Tier 0 页面只链接到最相关的 Tier 1 页面**，避免稀释权威。
3. **所有文章必须有“继续阅读”或“相关推荐”区块**，指向对应城市的其他高质量页面 + Pillar。
4. **禁止垃圾内链**：不要在每篇文章最后都塞一堆无关链接。

- 所有页面标题、H1、描述中对品牌表述保持高度一致。

## 5. 实施优先级

1. 先把所有 Tier 0 和 Tier 1 页面之间的内链做扎实（1-2 周内完成）。
2. 给已重写的 Tier 2 文章加上高质量相关推荐区块。
3. 制定内容生产模板，在新文章中自动包含正确内链。
4. 每季度审计一次内链健康度。
